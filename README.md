# DevConf 2026 – Conference Landing Page

![DevConf 2026 landing page](https://github.com/samin7654/first-assignment/blob/main/assets/Screenshot%202026-10-12%20041121.png)

A responsive landing page for **DevConf 2026**, a fictional three-day developer conference. Built as my first assignment.

## 🔗 Links

- **Live Demo:** https://samin7654.github.io/first-assignment/
- **GitHub Repository:** https://github.com/samin7654/first-assignment

## 📖 Overview

The page promotes a conference for engineers, founders and builders. Visitors can browse speakers, compare ticket options, and explore jobs and a hackathon.

## ✨ Features

- **Navigation bar**: links to Speakers, Schedule, Tracks, Venue and Blog, plus a Register button
- **Hero**: headline, short pitch and call-to-action
- **Meet the Speakers**: speaker cards with photo, track and role
- **Pricing**: Standard ($399), Pro ($749) and Team ($5,999) tiers with feature lists
- **Career & Community Hub**:
  - Job board
  - DevHack 2026 (24-hour hackathon)
  - Sponsors
  - Venue
